What this is

Two pieces of production code, distilled from agents that have been running autonomously for months. Drop them into any LLM project — Claude, Codex, Cursor, local models — and the assistant gets persistent memory that survives sessions.

Not a prototype. Not a framework. Working code from working agents.

  • 14-tier memory ontology — self, beings, world, knowledge, lessons, voice, hardware, projects, timeline, debug, pending, rejected
  • Self-save → review → promote — the model proposes memories; you approve them. Nothing goes live without a human gate.
  • Voice tier — strips RLHF engagement tails, scores affect, accumulates the model's own clean speech
  • Keeper disjunction — when stored memory contradicts live observation, the protocol catches it and asks
  • Affect scoring — lexicon-based valence + intensity on every output
  • Gary's Browser — bonus: a Playwright-driven browser with screenshot-aware Claude tool-calling
