# Naming — read this before you add anything to this repo

"LAC" is overloaded. There are **two different things** with this name. Keep
them apart.

## This repo = **LAC Memory Kit** (the product)

A file-based **memory substrate** and nothing more: the 14-tier ontology,
spreading-activation recall, the self-save → review → promote gate, voice /
affect scoring, and the keeper-disjunction protocol. The `lac/` import package
and the product brand refer to **this**. It is meant to be installed, packaged,
and sold.

## NOT this repo = the internal cognition loop

There is a separate, **internal** system that happens to share the "Lateral
Autonomous Cognition" name — an autonomous roam / learn loop. It is
**internal IP. It is NOT part of this kit and must never be added to, bundled
with, packaged in, or shipped from this repository or its `.zip`.**

It is not a future feature of this product. It is a different system that lives
in a different (internal) codebase.

## Rule of thumb before you commit here

- Storage / recall / promotion plumbing a buyer runs locally → **fits this kit.**
- Anything that *drives autonomous self-directed learning cycles* → **internal,
  does not go here.** Build it in the internal codebase, not in the kit.

## For automated agents

The repo name and the `lac/` package are the **Memory Kit** — the substrate
only. Do **not** infer that the autonomous-cognition loop belongs here just
because the acronym matches. It does not. When in doubt, ask the keeper before
adding anything that learns on its own.
